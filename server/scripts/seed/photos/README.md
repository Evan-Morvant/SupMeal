# Photos des recettes

Une photo déposée ici remplace la couverture peinte par `cover.mjs`, pour la
recette dont elle porte la **clé**. Le dossier peut rester incomplet : chaque
recette sans photo garde son aplat.

- **Nom du fichier** : la clé de la recette dans `../data/recipes.mjs`, suivie
  de `.jpg`, `.jpeg`, `.png` ou `.webp`. Exemple : `blanquette.jpg`.
- **Format** : 720 × 480 environ, JPEG de qualité 80. Au-delà de 1600 px de
  large, le poids ne se justifie plus — les vignettes font 330 px.
- **Licence** : le dépôt est public et ces fichiers partent dans le rendu.
  N'utiliser que des sources libres de redistribution — Unsplash, Pexels,
  Pixabay. Une photo trouvée par un moteur de recherche ne l'est pas.

Le compte rendu du peuplement indique combien de photos ont été trouvées.
Aujourd'hui les trente-quatre y sont :

```
34 recettes dont 29 publiques
34 photos fournies
```

Sur un dossier incomplet, il rappelle ce qui manque :

```
21 photos fournies, 13 couvertures peintes
```
